Druck-Helfer Windows-PC mit P-touch Editor und Drucker

Der Helfer lädt das Setup vom Server und startet es. Am Windows-PC fragt Windows nach Administratorrechten (Benutzerkontensteuerung) – dort mit „Ja“ bestätigen. Einstellungen und Autostart bleiben erhalten.

Installer herunterladen (empfohlen)
  1. ZIP herunterladen und entpacken (Rechtsklick → „Alle extrahieren …“) – Setup und helfer.vorgabe.yaml müssen im selben Ordner liegen.
  2. Labeltool-Helfer-Setup.exe starten. Meldet Windows SmartScreen „Der Computer wurde durch Windows geschützt“: „Weitere Informationen“ → „Trotzdem ausführen“; die Rückfrage nach Administratorrechten mit „Ja“ bestätigen.
  3. Installieren (Autostart ist voreingestellt). Am Ende öffnet sich der Assistent: Server und Token sind schon eingetragen – Vorlagen-Ordner und Druckermodell wählen, „Speichern & starten“.
  4. Später ändern: Startmenü → „Druck-Helfer einrichten“. Update: oben per „Helfer aktualisieren“ oder neues Setup drüber installieren. Voraussetzungen: P-touch Editor, b-PAC Client (64 bit) – kein Python nötig.

Auf diesem Server liegt kein Windows-Installer (z. B. selbst gebautes Image). Den Helfer gibt es hier als Python-Paket; der Installer ist bei den Versionen auf GitHub als Release-Asset erhältlich.

Alternative ohne Installation (Python nötig)
Helfer als Python-Paket herunterladen
  1. ZIP herunterladen und in einen festen Ordner entpacken (z. B. C:\Labeltool-Helfer).
  2. helfer.bat doppelklicken – beim ersten Start wird Python eingerichtet, dann öffnet sich der Assistent.
  3. Im Assistenten Vorlagen-Ordner und Druckermodell wählen (Server und Token sind schon eingetragen), „Speichern & starten“.
  4. Später ändern: helfer.bat einrichten. Voraussetzungen: Python 3, P-touch Editor, b-PAC Client (64 bit).

Beide Downloads enthalten die Server-Adresse und den aktuellen Helfer-Token (gibt es noch keinen, wird er beim Herunterladen erzeugt) – nicht weitergeben.
